# 철수·재배치 + 대기열

## 목표

단계 재생에 철수(Retreat)와 재배치를 넣고, 필드에 없는 편성 인원을 대기열로 보여준다.

## 데이터

- MAA 액션 중 `Deploy`(`部署`, type 생략)와 `Retreat`(`撤退`)을 단계로 쓴다. 나머지(스킬, 배속 등)는 무시.
- `Retreat`은 `name` 또는 `location`으로 대상을 찾는다.
- 배치 순번(배지 숫자) = 배치 액션의 등장 순서. 재배치도 새 순번을 받는다 (예: 7).
- 검증 (빌드 실패):
  - 이미 필드에 있는 오퍼레이터를 다시 배치 → `이미 배치됨: <이름>`
  - 다른 오퍼레이터가 있는 칸에 배치 → `칸 점유: <이름> [x, y]`
  - 필드에 없는 대상 철수 → `철수 대상 없음: <이름 또는 [x, y]>`
  - 기존 검증(모르는 오퍼레이터, 격자 밖, 배치 불가 타일, 방향) 유지.

## 함수 (`lib/strategy.ts`)

- `toSteps(copilot, board, operators): Step[]` — `Step = { kind: "deploy" | "retreat"; placement: Placement }`.
- `toPlacements` = 배치 단계의 placement만 (기존 호출부·테스트 유지).
- `frameAt(steps, squad, k)` — k단계까지 재생한 결과 `{ field, waiting, current }`.
  - `waiting`: 편성(`opers` 순서) 중 필드에 없는 인원, 상태 `"대기"`(아직 미배치) 또는 `"재배치 대기"`(철수함).
- `placementsUpTo` 삭제 (`frameAt`이 대체).

## 화면

- 보드: k단계가 배치면 그 오퍼레이터 시안 강조. 철수면 비워진 칸에 점선 테두리 + `철수` 표시.
- 대기열 (보드 아래, 조작 줄 위): 작은 아바타 + 상태 라벨. `재배치 대기`는 흐리게 + ↺. 방금 철수한 인원은 시안 테두리.
- 조작 줄의 `k / N`은 전체 단계 수(배치 + 철수).

## 범위 밖

재배치 쿨타임 숫자 (공략 데이터에 시간 정보 없음), 스킬 사용 표시.
